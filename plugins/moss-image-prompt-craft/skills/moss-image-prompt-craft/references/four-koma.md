# 4コマ漫画（yonkoma）テンプレート

MOSS-Image の Layout JSON（`canvas: "multi_panel"`）で縦4コマ漫画を1枚絵として作るための手順。
公式に4コマ専用の機能はない。ここにある値は、`layout.md` の仕様の範囲内で決めた推奨値。

完成例のドラフト: `templates/four-koma-draft.json`（コピーして書き換え、SKILL.md §4 の手順でコンパイルする）。

## 1. 起承転結を先に決める

JSONを書く前に、各コマで「何が見えるか」と「セリフ」を1行ずつ決める。コマのキャプションは
この1行を英語の視覚描写に直したもの。

| コマ | 役割 | 書くこと | 例（テンプレートの話） |
|---|---|---|---|
| 1 起 | 状況提示 | 誰が・どこで・何をしたいか。背景を一番しっかり描く | 塀の上の猫を見つけてスマホを構える「いた…！」 |
| 2 承 | 展開 | 1コマ目の行動を進める。同じ場所・同じアングル寄りで連続性を出す | 忍び足で近づく「そーっと…」 |
| 3 転 | 意外な出来事 | 予想を裏切る動き。集中線・大きなアクション・叫びの吹き出し | 猫が飛びかかってくる「えっ!?」 |
| 4 結 | オチ | 結果をひと目で分かる絵で見せる。セリフは短く、表情で笑わせる | 頭に猫を乗せて自撮り「…撮れた」 |

コツ:

- **オチは絵で見せる。** 4コマ目の面白さを文字の説明に頼らない（MOSSの文字描画が崩れても伝わるように）
- **転は視覚的に大きく変える。** アングル・効果線・キャラの大きさを1〜2コマ目と変える
- **同じキャラの外見を毎コマ書く。** 髪型・服・持ち物を `summary.caption` に固定し、各コマの `character` でも主要な特徴を繰り返す（省くとコマごとに別人になりやすい）
- **登場人物は2人（体）までに抑える。** 1コマあたりの `character` は1〜2個

## 2. キャンバスとコマ割り

推奨サイズ **768×2048**（約1.57M画素、16の倍数）。縦一列・4コマ均等割り。

| 要素 | bbox `[x_min, y_min, x_max, y_max]` |
|---|---|
| タイトル | `[224, 48, 544, 160]` |
| 1コマ目 | `[48, 192, 720, 624]` |
| 2コマ目 | `[48, 656, 720, 1088]` |
| 3コマ目 | `[48, 1120, 720, 1552]` |
| 4コマ目 | `[48, 1584, 720, 2016]` |

- 左右余白48px、コマ間の溝32px、各コマ 672×432
- タイトル不要なら、4コマを `y=48` から並べ直してよい（432×4＋32×3＝1824 → `48..1872`、高さを 1920 に詰める等。サイズを変えたら全bboxを再計算して再コンパイル）
- 横長に2×2で並べる場合は 1536×1024 などを使い、`summary.caption` に「read left-to-right, top-to-bottom」と読み順を書く

## 3. コマごとの items 構成

各コマは次の3種類をこの順で置く。座標はすべてキャンバス全体の絶対座標（コマ内のローカル座標ではない）。

1. **`object`（コマ枠＋背景）** — bbox はコマ全体。caption は `Panel N (setup/development/twist/punchline): a rectangular manga panel with a thick black border. ＋背景・小物・効果線`
2. **`character`（キャラの演技）** — bbox はコマ内側。caption にポーズ・表情・手元の物・キャラ同士の位置関係
3. **`text`（吹き出し）** — bbox は吹き出しの外形。caption に吹き出しの形（通常＝oval、ささやき＝dotted outline、叫び＝spiky/jagged outline、心の声＝cloud-shaped）と尻尾の向き、`text` にセリフ原文

吹き出しの注意:

- セリフは **1吹き出し 10文字前後・1〜2行** を目安に短くする。長いセリフは箱を広げるかコマを分ける（勝手に削らない）
- 改行位置を決めたいときは `\n` を入れる。縦書きを指定する場合は caption に `vertical Japanese text` と書くが、横書きの方が安定しやすい（未検証のため結果を見て判断する）
- 吹き出しはキャラの顔に重ならない位置（コマの上端寄り）に置く
- 擬音（ドキッ、ニャー等）も `text` item として置ける。caption に `bold hand-drawn sound effect lettering` などと書く

## 4. summary の書き方

- `meta`: `["yonkoma", "4-panel manga", "comic strip", "manga"]` を基本に、カラーなら `"full color"` を足す
- `canvas`: `"multi_panel"`
- `caption`: 全体の体裁（縦4コマ、白い紙、溝）、画風（線・トーン・カラー）、**キャラの固定外見**、読み順、吹き出しの体裁を1段落で

画風を変えるときは `art-style-picker` の `manga` / `monochrome` / `screentones` / `comic` などを英語で caption に足す。

## 5. チェックリスト

- [ ] 4コマ目だけ読んでもオチの絵が分かるか
- [ ] キャラの外見が summary と各コマで矛盾していないか
- [ ] 吹き出しの `text` がユーザー指定のセリフと一字一句一致しているか
- [ ] 吹き出しの箱が文字数に対して小さすぎないか
- [ ] すべての bbox がキャンバス内（0..width, 0..height）にあり、コマ同士が重なっていないか
- [ ] コンパイルが通ったか（`compile_prompt.py`）
- [ ] 納品時に `768x2048` などのサイズをプロンプト外に明記したか
