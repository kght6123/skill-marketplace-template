# 画風ピッカー

画風を考えるのは時間がかかるので、ユーザーは「出された候補から選ぶ／スキップする」だけで済むようにする。考えるのはClaudeの役割、ユーザーは選ぶだけ。

## 流れ

カテゴリ順に1ラウンドずつ進める（全5ラウンド、途中で終了可）:

1. `medium` 画材
2. `technique` 塗り・技法
3. `genre` ジャンル・テイスト
4. `era` 年代感
5. `lighting` 光・色調

構図・アングル・ポーズは扱わない。それらは composition-picker スキルの担当なので、ユーザーが構図も決めたそうなら最後にそちらを勧める。

各ラウンドで:

1. 候補を引く:
   `python <skill-dir>/scripts/pick.py --category <cat> --n 4 --exclude "<これまで提示したタグ>"`
   （スクリプトが使えない環境では `references/styles.tsv` を読み、自分でランダムに4つ選ぶ）
2. AskUserQuestion で提示する。`multiSelect: true`、各optionは
   - label: 日本語名（例「水彩」）
   - description: `タグ` ＋ 一言解説（例 `watercolor (medium)` — にじみと透明感）
   質問文にラウンド番号とカテゴリを入れる。「Other」欄で「スキップ」「別の候補」「ここで終了」と打てることを一言添える。
3. 回答の扱い:
   - 選択あり → 採用リストに追加して次へ
   - 「スキップ」→ 何も足さず次へ
   - 「別の候補」「引き直し」→ 同じカテゴリで除外付きで再抽選
   - 「終了」「もういい」→ まとめへ
   - 自由入力でタグや雰囲気が書かれたら、それも採用する

選択済みのタグと明らかに衝突する候補（例: monochrome 採用後の vivid colors）は引き直して避ける。矛盾した画風を勧めても選ぶ手間が増えるだけなので。

AskUserQuestion が無い環境では、番号付きリスト（1〜4＋「s:スキップ」「r:引き直し」「q:終了」）をテキストで出し、返事を待つ。

## まとめ

全ラウンド終了（または途中終了）したら次を出す:

1. 採用した画風の一覧（日本語名と一言の狙い）
2. 完成イメージを2〜3文で
3. コピペ用タグ:
   - **SDXL系**: カンマ区切りタグ。例 `watercolor (medium), lineless, pastel colors, soft lighting`
   - **Anima系**: 同じタグを使い、括弧内の `(medium)` 等はそのまま。アンダースコアは使わずスペース区切り
4. 相性メモ（効きが強すぎそうなタグや、重み調整 `(tag:1.2)` の提案があれば1〜2行）

最後に「構図も決める？（composition-picker）それともこのままキャラ込みのプロンプトにする？」と一言聞く。ひよりあかね用なら hiyori-prompt-craft スキルに画風タグを引き継いで完成プロンプトを作れる。

## メモ

- タグは Danbooru の一般画風タグのみ。特定アーティスト名は提案しない（ユーザーが自分で指定した場合は使ってよい）。
- 候補を増やしたいときは `references/styles.tsv` に行を追加するだけでよい（列: category, tag, ja_name, description）。
