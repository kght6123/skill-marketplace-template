# コマの演出（ショット・アングル・吹き出し・擬音）

各コマの演出を下書きするときに読む。spec の値はここの語彙だけを使う（スクリプトがそれ以外を拒否する）。

## 1. ショット（shot）

| 値 | 日本語 | 何が写るか | 向く場面 |
|---|---|---|---|
| `long` | 引き | 場所全体と人物 | 起。場所を見せたいとき |
| `full` | 全身 | 人物の頭から足まで | 動き・ポーズを見せたいとき（忍び足、転ぶ） |
| `medium` | ひざ上〜腰上 | 上半身と手元の動作 | 会話、物のやり取り |
| `bust` | 胸から上 | 表情と少しの手元 | オチの表情、会話の決め |
| `closeup` | 顔アップ | 顔だけ | 驚き・照れなど感情の山 |
| `extreme-closeup` | 目・手のアップ | 目や手、物の一部 | 緊張、決定的な一瞬 |

## 2. アングル（angle）

| 値 | 日本語 | 効果 |
|---|---|---|
| `eye-level` | 目線の高さ | 普通。迷ったらこれ |
| `high` | 俯瞰（上から） | 小さく弱く見える。失敗・落ち込み |
| `low` | あおり（下から） | 大きく強く見える。迫力・驚き・登場 |
| `birds-eye` | 真上から | 状況を説明する。散らかった部屋など |
| `over-shoulder` | 肩越し | 会話の相手を見ている感じ |

## 3. 4コマでの定番の配分

迷ったらこの配分から始め、ネタに合わせて1〜2か所だけ変える。

| コマ | ショット | アングル |
|---|---|---|
| 1 起 | `long` | `eye-level` |
| 2 承 | `full` か `medium` | `eye-level` |
| 3 転 | `medium` か `closeup` | `low`（迫力）か `high`（失敗） |
| 4 結 | `bust` | `eye-level` |

3コマ目は1・2コマ目と同じショット・アングルにしない（スクリプトが注意を出す）。

## 4. 吹き出し（balloons）

| type | 形 | 使う場面 |
|---|---|---|
| `normal` | 楕円 | 普通の台詞 |
| `whisper` | 点線 | ひそひそ声、小さな声 |
| `shout` | トゲトゲ | 叫び、驚き |
| `thought` | 雲形 | 心の声 |
| `narration` | 四角 | 語り（話し手なし） |

ルール:

- **読む順は右から左、上から下**（日本の漫画）。スクリプトは吹き出しをコマの上端に、配列の順で右から並べる。だから **先に話す台詞を先に書く**
- **先に話す人をコマの右に置く**。スクリプトがこの順でキャラを並べ替える。吹き出しの尻尾が交差しないため
- 1コマに吹き出しは **2つまで**。1吹き出しは **1行12字以内**、全体で25字以内。長い台詞は `\n` で改行するか、2つに分ける
- オチのコマ（結）の台詞は1つに絞る
- 台詞はユーザーが選んだ文言を一字一句そのまま使う

## 5. 擬音（sfx）

- 1コマに0〜1個が基本。動きのある承・転に向く（ソロ…、バッ、ドキッ、ガーン）
- スクリプトはコマの左の中ほどに置く（日本式では左が最後に読まれる位置なので、余韻の音に合う）
- 描き方を変えたいときだけ `caption_en` を書く（例 `Large jagged sound effect lettering bursting outward.`）

## 6. キャラの見た目をそろえる

- `characters[].look_en` に、髪型・髪色・服・持ち物を **毎回同じ言葉で** 書く。生成時に全コマへ繰り返し入れる
- 見た目の特徴は3〜4個に絞る。多すぎるとコマごとに一部だけ拾われてばらつく
- `acting_en` には動作と表情だけを書き、見た目は書かない（矛盾を防ぐ）
- 1コマに2人まで。3人目は別のコマに出す
