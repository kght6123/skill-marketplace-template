# 話の組み立て

ネタ案を作るときに読む。ユーザーは漫画に詳しくない前提なので、ここにある型で骨組みを作り、ユーザーには「どの案が好きか」だけを選んでもらう。

## 1. 起承転結の役割

| コマ | 役割 | 読者に起きること | 書き方 |
|---|---|---|---|
| 1 起 | 状況提示 | 「誰が・どこで・何をしようとしているか」が分かる | 場所が分かる引きの絵。台詞は目的か気持ちを一言 |
| 2 承 | 展開 | 「うまくいきそう」「こうなるはず」と予想する | 1コマ目の行動を進める。場所とアングルは近いままにして、つながりを見せる |
| 3 転 | 裏切り | 予想が外れて「えっ」となる | 起きることを絵で大きく見せる。寄り・あおり・集中線など、絵の調子を変える |
| 4 結 | オチ | 笑う・ほっこりする・納得する | 結果をひと目で分かる絵にする。台詞は短く、表情で決める |

大事なのは **2コマ目で読者に予想させ、3コマ目でそれを外す** こと。2コマ目が弱いと3コマ目が意外に見えない。

## 2. オチの型

オチの型は `references/catalog.tsv` の `ending`（13種）から、Step 1 でランダムに4つ引いて選んでもらう。ここでは代表の4種の仕組みを示す。ほかの型（天丼・無言オチ・ループなど）は、catalog.tsv の説明に沿って組む。

| 型 | spec の ending | 仕組み | 例 |
|---|---|---|---|
| ボケ | `boke` | 主人公がずれた行動・勘違いをして、それが結果になる | 掃除をがんばったら物が全部押し入れに詰まっていただけ |
| どんでん返し | `reversal` | 立場や結果が逆転する | 猫を撮るつもりが、猫に乗られて自撮りになる |
| ほっこり | `wholesome` | 小さな失敗のあとに、やさしい結末 | 料理を焦がしたが、家族が「これが好き」と言う |
| ツッコミ | `tsukkomi` | 2人目が4コマ目で冷静に指摘して落とす | 長い準備の末に「それ今日じゃないよ」 |

## 3. ジャンル別のネタの作り方

ジャンルは `catalog.tsv` の `genre`（14種）から引く。下の表にないジャンルは、そのジャンルらしい小さな事件を1つ決め、起承転結に当てはめる。

| ジャンル | spec の genre | ネタの出し方 |
|---|---|---|
| ギャグ | `gag` | 日常の「あるある」を1つ選び、3コマ目で極端にする |
| 日常 | `daily` | 季節・食べ物・家事など身近な題材。オチはほっこりかボケが合う |
| ラブコメ | `romcom` | 2人の距離が縮まりそうで縮まらない。3コマ目で照れや勘違い |
| 解説 | `explainer` | 1〜2コマ目で困りごと、3コマ目で解決策を見せ、4コマ目で効果を見せる。説明は台詞ではなく絵で |
| ちょっとシリアス | `drama` | 3コマ目で静かな事実を見せ、4コマ目は台詞なしの余韻でもよい |

## 4. ネタ案の出し方

- 材料（題材・舞台・転の仕掛け）は `catalog.tsv` からランダムに引く（SKILL.md の Step 3）。仕掛けは3コマ目（転）に使う

- 毎回 **3案** 出す。3案は型かジャンル内の切り口を変える（同じ話の言い換えを並べない）
- 1案は「タイトル＋起・承・転・結を各1行（台詞つき）」で書く。例:
  - 『ねこ撮影』 起: 塀の猫にスマホを構える「いた…！」／承: 忍び足で近づく「そーっと…」／転: 猫が飛びかかる「えっ!?」／結: 頭に猫を乗せて自撮り「…撮れた」
- ユーザーの題材があれば必ず使う。なければジャンルから身近な題材を選ぶ
- 登場人物は1〜2人で回る話にする（4コマに3人以上出すと、描き分けと台詞が足りなくなる）

## 5. よくある失敗と直し方

| 失敗 | 直し方 |
|---|---|
| 3コマ目が2コマ目の続きで、驚きがない | 3コマ目で起きることを「予想と逆」にする |
| オチを台詞で説明している | 4コマ目の絵だけで結果が分かるようにし、台詞は一言にする |
| 1コマ目で状況が分からない | 1コマ目を引きの絵にして、場所と目的を見せる |
| 台詞が長い | 1吹き出し12字以内。収まらないならその情報は絵で見せる |
| 4コマ全部が同じ絵に見える | 転かオチでショットかアングルを変える（direction.md） |

## 6. 8コマ（4コマ×2列）

右の列を先に、上から下へ読み、次に左の列を読む。2つの組み立て方がある。Step 3 で、ネタ案ごとに Claude が合うほうを決めて書き、案を選んでもらうことで決まる。

| 組み立て | 向く場面 | 書き方 |
|---|---|---|
| 2本立て | 同じキャラで小ネタを2本 | 4コマを2本。題材は同じテーマでそろえ、2本目のオチを少し大きくする |
| 前後編 | 1本では収まらない話 | 1本目の結を「小さなオチ＋次の引き」にし、2本目の起はその続きから始める。2本目の結が本当のオチ |

- どちらも各列は起承転結を1回ずつ持つ（スクリプトが確認する）
- 列ごとのタイトル（`hachikoma-title`）は、2本立てなら各話の題、前後編なら「前編の題」「後編の題」にする
- 1本目と2本目で、キャラの見た目と場所の描き方をそろえる（`look_en` は共通）

## 7. 1ページ

1ページは、起承転結をコマ数に合わせて配分する。テンプレートのコマ数が決まっているので、どの役割に何コマ使うかを先に決める。

| コマ数 | 配分の例（読む順） |
|---|---|
| 5コマ | 起・承・承・転・結 ／ 起・承・転・転・結 |
| 6コマ | 起・承・承・転・転・結 ／ 起・起・承・承・転・結 |
| 4コマ（正方形） | 起・承・転・結 |

- **大ゴマ（一番大きいコマ）に何を描くかを先に決める。** 起なら場所や登場の見せ場、転なら山場、結ならオチ。承に大ゴマを使うと、話が止まって見える（スクリプトが注意を出す）
- テンプレートの選び方：オチを大きく見せたい → `page-big-ending-5`、最初に場所や人物を印象づけたい → `page-big-opening-5`、高さや全身を見せたい → `page-tall-5`、迷ったら `page-basic-6`
- SNS向けの正方形（1536×1536）は4コマ。4コマの起承転結がそのまま使える。基本は正方形のコマ4つの `page-square-4`（各コマ708×708）で、右上→左上→右下→左下の順に読む。オチを大きくしたいなら `page-square-big-ending-4`
- 1ページの最後のコマ（左下）は、読者の目が最後に止まる位置。オチの絵はここに置く
- 台詞の総量は4コマより増やしてよいが、1コマ2吹き出し・1吹き出し12字の目安は同じ

## 8. 2ページ

2ページは、1ページ目（右ページ）→2ページ目（左ページ）の順に読む。起承転結は2ページ通しで1回にする。読者に2ページをどう見せるかで、組み立てが変わる。Step 3 で、ネタ案ごとに Claude が合うほうを決めて書き、案を選んでもらうことで決まる。

| 見せ方 | `page_turn` | 組み立て |
|---|---|---|
| 見開き | `spread` | 2ページが同時に目に入る。結（オチ）は2ページ目の最後（左下）のコマだけに置き、先に目に入らないようにする |
| めくり | `turn` | 1ページ目を読んでから、めくって2ページ目を見る。1ページ目の最後を「引き」（続きが気になる場面）にし、2ページ目の最初のコマに転を置く。めくった瞬間に驚かせられる |

配分の例（10コマ）:

| ページ | 配分の例 |
|---|---|
| 1ページ目 | 起・起・承・承・承（最後は引き） |
| 2ページ目 | 転・転・転・結・結（最後の大ゴマがオチ） |

- 1ページ目の大ゴマは起（場所や人物の登場）、2ページ目の大ゴマは結（オチ）に使うと、迷わず組める
- 見開きなら `spread-climax-8` で、2ページにまたがる大ゴマに山場かオチを置ける。読者が見開いた瞬間に目に入るので、一番見せたい絵に使う（めくりでは使えない）
- 2ページで登場人物を増やしたくなるが、3人までにする（描き分けが崩れる）
- スクリプトは、めくりで2ページ目の頭が転でないとき、見開きで1ページ目に結があるときに注意を出す
